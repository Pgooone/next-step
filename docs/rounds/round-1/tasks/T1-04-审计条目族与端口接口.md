## 依赖

## 实现要点
- **审计条目族 v1（H3 定案：六类冻结，后续加类型走扩展流程）**：`packages/core/src/audit/entries.ts` 定义六类 payload（对齐详细设计 §1.3）：
  `artifact_proposed`（changeId/artifactId/baseVersion/diffBlockCount/sourceActor/diffSummary）
  `artifact_resolved`（changeId/artifactId/newVersion/acceptedBlocks/rejectedBlocks/**sourceRefs**）
  `artifact_rollback`（artifactId/fromVersion/toVersion/newVersion/undoing/note）
  `approval_request`（changeId/artifactId/status:"pending"/mode/requester）
  `approval_response`（changeId/artifactId/status: **"resolved" | "discarded"** /decisions/via）——**status 扩展 "discarded" 是本卡对 P1-2 discard 审计的承接**（discarded 时 decisions=[]，note 说明放弃原因，如「上游版本已变更，提案作废」）
  **`artifact_external_resolved`（H3 新增第六类：action: "merge" | "reject"，artifactId/action/note——拒绝采纳不是 PendingChange 全决，不并入 artifact_resolved，避免污染 acceptedBlocks/sourceRefs）**
  顶层壳 `AuditEntryPayload { ns:"next-step", kind, ts, presentation? }`。
- **P1-3 类型承接**：approval_request 的**写入责任归 gate 编排**（T1-05 实现），本卡只定义类型与构建函数，注释写明「仅在 ask 路径由 gate 写入；Web 面板直接写回无问询 → 不产生 request 条目」。
- **DecisionPort（P1-1①）**：`packages/core/src/gate/ports.ts` 定义 `DecisionRequest`（kind:"approve_blocks"、changeId/artifactId/title/blocks/mode）与 `Decision`：
  `{ status:"resolved"; decisions:{blockId,decision:"accept"|"reject"}[] } | { status:"deferred" } | { status:"cancelled" }`——**cancelled 分支**语义：调用方（gate）收到 cancelled 后 **pending 保留**、工具返回「已提案未确认，changeId=…，可用 Web 面板或重试处理」（T1-05 承接）。
- **AuditPort**：`append(entry: AuditEntryPayload): Promise<void>`（L2 提供 pi 实现，T1-07）。
- **presentation（P1-5）**：`packages/core/src/presentation/` 定义 `Presentation { title, badges, body }` 与 `DiffBlockPresentation.state` 枚举加 **"rolledback"**（「回滚后 v4 提案块灰化标『未生效』」的数据表达，S3④ 渲染依赖）；`DiffRef/Row/Banner/Text` 块类型对齐详细设计 §1.4。
- **sourceRef + blockAnchor 基线（H6 + P2-4 落点，本卡定死格式）**：`SourceRef { artifactId, version, blockAnchor:{ lineStart, lineEnd, heading? } }`；`buildSourceRefs(change, newVersion): SourceRef[]`——**del/mod 块锚 oldContent 行号**（LCS ops 直接可推，equal/del 有 old 行号）；**add 块锚「块前最近 equal 行 +1 行、lineEnd 同」**（无旧行的基线规则，P2-4 定案）；heading = 向上找最近标题行（尽力而为，H6 采纳）。
- 各条目类型的 presentation 构建函数（buildApprovalPresentation 等），输入领域状态 → 输出 Presentation（5 块提案样例与原型结构对齐）。
