## 一句话

Next-Step v2.0 是一条本地多 Agent 产线：把「一句想法」变成「可动工的设计包 + 可评审的原型」；每步产物受管、可逐块签字、可追溯；成品出缺陷时沿追溯链归因到阶段、只重跑下游。

## 三根柱子（主干判据）

产能 / 可控 / 可追溯返工。任何新功能必须写明落在哪根柱子、让哪条 AC 从红变绿，写不出不做。

## 不可协商约束（F1–F6）

- F1 一切落盘产物的改动必经「提案 → 逐块确认 → 新版本」🔒
- F2 大动作前有计划闸；失败最多自重试 1 次 🔒
- F3 本地优先、纯文件、无数据库、单用户 🔒
- F4 fork 0.84.2 基线，改动只限品牌/发行层（D1 拍板）🔒
- F5 领域层与 UI/内核解耦（L1 零 pi 依赖、零 UI 依赖）
- F6 每条需求必须有可断言验收标准

## 三条病根（本次重构要解的）
